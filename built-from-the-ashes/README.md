# Built From The Ashes — rough-cut music video (Remotion)

A hand-editable, beat-synced rough cut for the Noke Van Co. song *Built From The Ashes* (4:51).
Everything about the edit lives in one file, `timeline.json`. Media comes from a folder you ingest.
No paid services: Remotion renders locally with its bundled FFmpeg.

```
npm install
npm run placeholders          # (already done) stand-in stills/clips so it renders with no media
npm run ingest -- <folder>    # pull in your real photos/clips (HEIC → JPG, videos → 720p proxies)
npm run timeline:check        # print the resolved shot list + warnings for timeline.json
npm start                     # Remotion Studio: scrub the edit in the browser
npm run preview               # 1280x720 preview → out/preview-720p.mp4
npm run final                 # 1920x1080 → out/final-1080p.mp4
```

Windows note: everything is an npm script and plain Node, no bash required.
If Remotion cannot download its headless Chrome (locked-down network), set `REMOTION_BROWSER_EXECUTABLE` to
your Chrome/Chromium/Edge path before rendering.

## What is in here

| Path | What it is |
| --- | --- |
| `timeline.json` | The edit decision list: section times, which media pool plays where, cut pace, overlays. **Edit this.** |
| `public/media.json` | Manifest of every media file and its pool. Generated by `npm run ingest`; safe to hand-edit `pool`. |
| `public/media/` | Ingested media (not committed). `placeholders/` are generated stand-ins. |
| `public/audio/built-from-the-ashes.m4a` | The song, re-muxed to AAC (the original was Opus in M4A with a subtitle track). |
| `public/lyrics/lyrics.srt`, `lyrics.txt` | Timed lyrics and section labels extracted from the song file's metadata. |
| `public/analysis.json` | Beat tracking + energy curve (librosa). Tempo 95.7 BPM, first beat at 2.65 s. |
| `src/resolve.ts` | Pure function: timeline + manifest → list of shots with absolute times. |
| `src/Video.tsx`, `src/components/` | The Remotion composition: Ken Burns shots, beat punch, logo/text/counter/end card overlays. |
| `scripts/ingest-media.mjs` | Folder → `public/media/<pool>/…` + `media.json`. Converts HEIC, makes H.264 proxies. |
| `scripts/make-placeholders.mjs` | Generates labeled placeholder stills (SVG) and clips (MP4) for every pool. |
| `scripts/check-timeline.mjs` | Validates `timeline.json` and prints the shot list. |

## Media pools

The ingest script sorts each file into a **pool** by the nearest folder name, then by words in the file name,
then `misc`. Pool keywords (see `POOLS` in `scripts/media-lib.mjs`):

| Pool | Folder or file-name keywords |
| --- | --- |
| `rvtv-old` | rvtv-old, old, before |
| `rvtv-aftermath` | aftermath, after |
| `rvtv-new` | rvtv-new, new, rebuild, reopen, grand |
| `fire` | fire, flames, blaze, burn, night |
| `rubble` | rubble, debris, damage, ash(es), cleanup |
| `community` | community, support, fundraiser, donation, volunteer, shirts |
| `shop` | shop, garage, bay, warehouse |
| `crew` | crew, team, staff, employees |
| `early` | early, first, throwback, 2019…2023 |
| `roadtrip` | roadtrip, road, trip, travel, camp, mountains, beach, sunrise |
| `build` | build, wiring, electrical, cabinets, install, solar, closeup, detail |
| `vans` | vans, van, finished, final, delivery, sprinter, transit, promaster, interior, exterior |
| `social` | social, reel, tiktok, instagram |
| `logo` | logo, brand, wordmark (first image here is used by the logo overlay and end card) |

Easiest layout for the folder you hand over:

```
my-media/
  rvtv-old/   rvtv-aftermath/   rvtv-new/
  fire/  (name the loading-dock shot "loading-dock-*.jpg")
  rubble/  community/  shop/  crew/  early/  roadtrip/  build/  vans/  social/
  logo/noke-van-co.png
```

Then `npm run ingest -- "C:\path\to\my-media"`. The script prints where each file landed and lists anything
that fell into `misc`; fix those by renaming/moving the file and re-running, or by editing `"pool"` in
`public/media.json`. Videos become 720p H.264 proxies (silent) so iPhone HEVC clips play in the Studio and
render fast; pass `--no-proxy` to keep originals.

## Editing timeline.json

Every time is **seconds from the start of the song**. After any change, run `npm run timeline:check` to see
the resolved shots and any warnings, then `npm run preview` (or just watch it in `npm start`).

### Move a section boundary

Sections must stay contiguous: change the `end` of one and the `start` of the next to the same number.

### Change what plays where

Each section has `shots`: a list of **blocks** that fill time in order, from the previous block's end up to
`until` (default: the section end).

```jsonc
{ "pool": "fire", "until": 103.7, "beatsPerCut": 4 }           // cycle through the fire pool, cut every 4 beats
{ "pool": ["vans", "crew", "logo"], "beatsPerCut": 1 }         // round-robin across pools, cut on every beat
{ "src": "media/fire/IMG_0412.jpg", "until": 20.0 }            // hold one specific file (path from public/media.json)
{ "match": "loading-dock", "pool": "fire", "until": 20.0 }     // first file whose path contains "loading-dock"
```

Per-block options:

- `beatsPerCut` — cut pace. 1 = every beat (0.63 s), 2 ≈ 1.25 s, 4 ≈ 2.5 s, 8 ≈ 5 s, 16 ≈ 10 s. Cuts snap to the beat grid.
- `transition`: `"cut"` (default) or `"dissolve"`, with `transitionSeconds`.
- `effect`: `zoomIn`, `zoomOut`, `panLeft`, `panRight`, `none` (otherwise they rotate automatically).
- `kenBurns`: how far stills move, as a scale factor (1.12 = 12 %). Video clips get 30 % of that as a gentle drift.
- `note`: free text, ignored by the renderer.

Section-level `"beatPunch": true` adds a scale/brightness hit on every beat (used on the choruses).

### Overlays

```jsonc
{ "type": "logo",    "at": 20.0,   "duration": 8.5, "style": "hit" }                         // "hit" or "fade"
{ "type": "text",    "at": 236.66, "duration": 6.3, "text": "Someday is a decision.", "style": "quiet" }
{ "type": "counter", "at": 123.48, "duration": 2.5, "from": 1, "to": 26, "label": "BUSINESS DAYS", "hold": 2.5 }
{ "type": "endcard", "at": 277.6,  "duration": 13.6, "title": "Noke Van Co.", "subtitle": "Live your adventure", "fadeIn": 1.5 }
```

`logo` and `endcard` use the first image in the `logo` pool when there is one; otherwise a typographic wordmark.

### Beat grid

`beat.bpm` and `beat.firstBeat` define the grid every cut snaps to. If cuts feel early or late everywhere,
nudge `firstBeat` by ±0.1 s. Detected beats are listed in `public/analysis.json` if you want to check.

### Debug readout

`"debugOverlay": true` prints section, song time, shot number and file name in the corner of every frame so
you can say "swap #72". Set it to `false` for the real render.

## Re-rendering

```
npm run preview          # 720p, fast settings (about 4 min with placeholders on 4 cores; real photos and clips take longer)
npm run preview:fast     # half-resolution scrub copy when you only need timing
npm run final            # 1080p, high quality
npx remotion render BuiltFromTheAshes out/verse2.mp4 --frames=2811-4461   # just one section (frames = seconds × 30)
```

Remotion Studio (`npm start`) shows every shot as a named sequence in its timeline, so you can scrub to any
cut and read its number from the debug readout.
