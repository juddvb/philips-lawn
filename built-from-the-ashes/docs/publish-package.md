# Publish package — what is in the zip and what to do with it

```
built-from-the-ashes-publish/
  final-1080p.mp4            full music video, 1920x1080, 4:51, clean (no debug readout)
  thumbnail.jpg              1280x720 YouTube thumbnail (fire frame, logo, "26 business days")
  captions-lyrics.srt        timed lyrics for YouTube Subtitles
  youtube.md                 title options, description with chapters, tags, upload settings
  reels/
    ReelHook.mp4             35 s  post 1st
    Reel26Days.mp4           30 s  post 2nd
    ReelChorus.mp4           20 s  post 3rd
    ReelSomeday.mp4          32 s  post 4th
  reels.md                   captions, hashtags, platform notes, handoff prompt
```

## Order of operations

1. Confirm the two rights items in `youtube.md` (Suno plan that generated the song; OK from people on camera).
2. Upload `final-1080p.mp4` to YouTube with `youtube.md` (title, description, tags, settings), `thumbnail.jpg`,
   and `captions-lyrics.srt`. Publish as Unlisted first, check it on a phone, then switch to Public.
3. Put the YouTube link in the Instagram / TikTok bio.
4. Post the four Reels in the order above, one every 2 to 3 days, with the captions in `reels.md`.

## Handoff prompt (full package)

```
Attached is a publish package for Noke Van Co., a custom camper van builder in Roanoke, Virginia. Their shop burned on April 4, 2025 and reopened 26 business days later; this is a music video about it.

1. Upload final-1080p.mp4 to the Noke Van Co. YouTube channel. Use the first title option in youtube.md, paste the description exactly (fill the bracketed links first), add the tags, upload thumbnail.jpg and captions-lyrics.srt, apply the settings table, and publish as Unlisted. Send me the link.
2. After I confirm, switch it to Public.
3. Then post the four Reels from reels.md in order, one every 2 to 3 days, to Instagram Reels, TikTok, YouTube Shorts and Facebook Reels, with the captions exactly as written, the original audio, the fire frame as cover, and the YouTube link where it says "link in bio".
Do not add music, filters, auto-captions, trending sounds or AI voice-over. Ask me before changing any wording.
```
